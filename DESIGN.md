# Pontinho

Placar para usar com uma mão no celular, entre rodadas de uma mesa de baralho.

| Papel | Cor |
| --- | --- |
| Fundo | `#111713` |
| Superfície | `#19231d` |
| Destaque da mesa | `#223e2f` |
| Texto principal | `#f5f2e7` |
| Texto secundário | `#b1c0b4` |
| Ação principal e seleção | `#dcf586` |
| Eliminação e erro | `#ffb5a9` |

O título serifado e as cartas de CSS remetem à mesa. A interface de jogo usa
uma fonte do sistema e números tabulares. O placar mantém a ação principal
ao alcance do polegar. A etapa de perdas mostra os adversários em uma lista
compacta, com controles de pelo menos 44 px e confirmação após a última linha.
Em telas baixas ou com teclado aberto, a página pode rolar normalmente.

Movimento sinaliza o resultado da rodada ou o fim da partida. A interface
respeita a preferência de movimento reduzido.
